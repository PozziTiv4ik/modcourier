# Example configuration

Copy modcourier.json into **your mod's directory**, or preferably run init there
to generate it from your actual JARs.

Replace all example metadata and artifact paths. MIT is an example, not a license
decision for your mod. Set exact versions you tested, actual dependencies and the
real extent of AI usage.

Existing project IDs can be recorded with bind; new CurseForge projects require
the author-dashboard step in [setup](../docs/setup.md).
